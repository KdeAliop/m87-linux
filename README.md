m87linux is a distribution based on Fedora,
designed to be inclusive of all users and provide support,
with the goal of making the distribution simple for everyone.
I hope you like it because I put a lot of work into it (: 



You'll need a USB flash drive and software to burn the operating system to it,
such as Rufus, Ventoy, or any other program you prefer. Download the ISO file,
then use the software to burn the ISO to the flash drive. Restart the device,
enter the boot menu,
select the flash drive, 
and load the distribution from the drive.
This is just a simplified explanation.
Take care.
